# モジュールを開発者テンプレートに統一

**機能ブランチ:** add-font-files-module

## パッケージの参照先と開発者向けガイド

リリース 1.0.3 — パッケージ検証では、エントリーポイント、アイコン、バナー、スクリーンショットが、解決済みのパスを含めチェックアウト内の通常ファイルであることを確認します。ドキュメントは公開契約を説明し、リリースのメタデータにはマニフェストを参照します。変更履歴にはリリースの来歴を保持します。 フォントの既定値、カタログ検索、ファミリーの書式、保存済みファミリーの解析、HTMLエスケープはホストの再利用契約を使用します。設定は表示中のプレビューを更新し、アンマウント時に保留中の描画を停止します。保存は引き続きスコープ付きの設定フローを使用します。

## 標準構成と所有範囲を守る統合

テンプレートの指針、ドメイン別ルート、翻訳された統合文書、実行可能な構成チェック、最終パッケージハッシュを同期します。公開URLとモジュール識別子は維持します。ブラウザーの提供機能は担当ホストのライフサイクル契約に従います。

## Marketplace の説明を統一する

Marketplace のメタデータに短い操作概要と具体的な機能説明を使用し、翻訳の意味を揃えます。
